# GStep 36문항 내용 검수

검수일: 2026-09-22. 기준 문서: [제공된 GS25 교육맵 요약](gs25-store-manager-training-map.md). 사용자 요청에 따라 기존 36문항 전체의 상황, 발화 상대, 수행 과제, 선택지, 정답 설명, 서술형 평가 기준을 대조했다. 원본 영상 전체나 최신 운영 정책을 새로 검증했다는 의미는 아니다.

## 결과와 변경 범위

- 36/36문항 검수, 객관식 31개와 서술형 5개. 모든 출처는 제공 문서의 **본문 요약 확보** 항목이다. 미확보 본문을 근거로 사용하는 문항 0개, 정답 선택지 중복 0개, 근거가 없는 법률·안전 수치 0개.
- 모든 문항에 `speakerLabel`과 `mission`을 지정했다. 기존 helper가 상황문을 발화에 복제하던 25문항은 대사 또는 업무 상태문으로 분리했다. 업무 안내와 고객 발화를 혼동하지 않도록 화면이 이 필드를 사용한다.
- 서술형 5문항의 일괄 질문을 상황별 질문으로 바꾸고 `responseLabel`, `answerPlaceholder`를 지정했다. 그중 인수인계 2문항은 상대를 다음 근무자로, 화면을 `report`로 고쳤다. 고객에게 사과하라는 일괄 지시를 요구하지 않는다.
- 출처 범위가 불명확한 2문항을 수정했다. `stock-difference`는 **담배** 재고 조사, `hotpot-clean`은 **어묵기** 세척으로 한정했다. 냉장 설비 점검은 과다 적재의 위치를 설비 안으로 명확히 했다.
- 서술형 5개 rubric의 각 항목이 실제로 확인할 의미를 구체화했다. Gemini에는 상황뿐 아니라 상대, 발화, 질문, 수행 과제를 함께 전달한다. 화면에 없는 수량이나 세부 사실을 추측해서 답하도록 요구하지 않는다는 제약을 추가했다.
- 객관식 선택지 문구·ID·정답 ID는 모두 보존했다. 제목 2개와 상황·안내만 바뀌므로 기존 학습 정답 해석은 변하지 않는다. 과거 12문항 `legacyTrainingSteps`는 JSON SHA-256 고정 검증으로 완전 동일함을 확인했다.

## 검증과 남은 한계

- 수정 전 `training-content.test.ts`: 3개 중 2개 실패를 재현(상대/미션 누락, 잘못된 인계 화면). 출처/legacy 보존 검사는 처음부터 통과.
- 채점 문맥 테스트는 수정 전 실패를 재현(실제 상대·발화·미션이 Gemini 입력에 없음).
- 수정 후 `npx vitest run src/features/training/training-content.test.ts src/features/training/training-grader.test.ts src/features/training/training-engine.test.ts src/features/training/training-v2.test.ts`: **17/17 통과**. `npm run typecheck`: exit 0.
- 이 검수에서 Gemini 실호출은 하지 않았다. 서버 채점 문맥은 provider mock으로 검사했고, 기본 채점은 demo로 확인했다. 키워드 기반 demo는 의미·부정 표현을 완전히 판단할 수 없으며 실제 AI 평가와 구분 표시한다.
- 36문항의 내용 검수에서 남은 차단 항목은 0개다. 전체 제공 문서의 모든 항목을 36문항으로 가르친다는 주장은 하지 않는다. 본문 미확보 20편, 현재 법률·환불 조건·설비 수치 등은 추가 확인 없이 출제하지 않는다.
- 화면의 실제 36단계 조작, 전체 회귀 테스트와 production build는 부모 에이전트가 통합 변경 기준으로 별도 기록한다. 이 문서는 해당 검증을 대신하거나 실행 전 성공으로 기록하지 않는다.

## 실제 Computer Use 검수 — 2026-09-22

자동 E2E와 별도로, Edge의 실제 서비스에서 문항을 읽고 답을 선택/입력해 제출했다. 수정 전 36단계와 수정 후 36단계를 각각 최종 결과까지 완료했고, 두 과정 모두 36개 기준 충족/100점이었다. 서술형은 각 과정에서 5개 모두 실제 Gemini 의미 채점으로 확인했다. 정답 키를 브라우저 저장소에 주입하거나 단계를 건너뛰지 않았다.

수정본에서는 다음 근무자 인계 2문항의 상대·미션·입력 라벨, 고객 서술형 3문항의 개별 질문, 일반 업무와 POS 화면 구분, 담배 재고·폐기 대상·어묵기 명칭, 해설을 확인했다. 다음 근무자 인계 화면은 실제 스크린샷으로도 확인했다. 중단된 검수는 기존 탭의 5단계 제출 완료 상태를 읽고 재개했다.

AI 대화 3종도 실제 Gemini와 답변을 주고받고 평가까지 확인했다. 행사 문의는 제공된 가격·동일 상품 조건을 안내했고, 대기 불만은 계산 대기임을 질문으로 확인했다. 환불 문의 고객은 질문에 맞춰 봉지 과자, 벌어진 옆면, 카드 결제 내역을 일관되게 제시했다.

추가로 발견한 AI 평가 결함은 별도 수정 대상으로 기록했다: 정확한 행사 제한 설명을 공감 부족으로 비판하는 것, 미제공 연락 시점을 당일로 약속하도록 권하는 것. 학습자가 알 수 없는 정보나 일반 문의에 불필요한 사과를 감점 근거로 삼지 않도록 상황별 지침을 보강하며, 점수 자체를 특정 값으로 고정하지 않는다. 최종 수정 후 실제 재검증 결과는 progress.md의 후속 기록을 따른다.

최종 재검증: 동일한 행사·환불 답변을 최종 배포본에서 실제 Gemini에 다시 제출했다. 행사 평가에서는 확인된 조건을 정중하게 설명한 점을 인정했고, 환불 평가에서는 경영주 답변 가능 시점을 먼저 확인하는 선택적 연습만 제안했다. 두 재검증은 각각 100점이었으나 점수를 강제한 변경은 없으며, 관찰된 예시의 결과다. 최종 전체 회귀는 단위·통합 139개, 브라우저 E2E 58개와 production build가 모두 통과했다. 배포 원본은 75e6cc2이며 실제 서비스는 https://gs-hack-seven.vercel.app 이다.
