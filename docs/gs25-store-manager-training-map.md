# GS25 스토어매니저 교육맵 공개 자료 정리

> 출처: [GS25 스토어매니저 교육맵](https://hpimg.gsretail.com/images/gs25/winwin/web/store_manager_map.html)  
> 확인일: 2026-09-21  
> 활용 목적: 첫날.zip의 합성 시나리오·매뉴얼·체크리스트 후보를 설계하기 위한 공개 자료의 **제목·분류·링크 메타데이터** 정리

## 먼저 지켜야 할 범위

- 이 문서는 공개 교육맵의 구조와 링크 제목을 정리한 참고 자료다. 링크된 영상의 전체 내용이나 실제 점포 운영 절차를 복제한 매뉴얼이 아니다.
- 실제 GS25 POS, 상품, 재고, 매출, 사내 시스템, 개인정보는 첫날.zip에 사용하지 않는다.
- 아래 항목을 제품에 적용할 때는 실제 브랜드·화면·수치 대신 가상 매장과 합성 상품·절차로 다시 설계한다.
- 법률·안전·결제·연령 확인 관련 내용은 오래되었거나 변경될 수 있으므로 서비스가 확정 답변하지 않고 최신 공식 지침 또는 경영주 확인으로 연결해야 한다.
- 원본 링크와 제공 상태는 변경될 수 있다. 구현 데이터로 고정하기 전에 링크 유효성과 공개 범위를 다시 확인한다.

## 첫날.zip에 바로 반영할 우선순위

### P0 문서·Seed에 반영 가능한 것

1. **교육 분류 체계**: `고객 응대`, `상품·소비기한`, `안전·시설`, `POS`, `결제`, `서비스 판매`, `디지털 도구`를 매뉴얼 카테고리 후보로 사용한다.
2. **행동 중심 시뮬레이션**: 질문을 받으면 먼저 가상 POS 또는 매뉴얼을 조회하고, 근거가 없으면 경영주 확인을 요청하도록 한다.
3. **체크리스트 템플릿**: 상품 검수, 소비기한 확인, 진열/가격표 확인, 시설·위생 확인을 합성 항목으로 제공한다.
4. **미해결 질문 분류**: VOC, 소비기한, POS, 결제, 택배·픽업, 설비, 안전 등으로 태그해 경영주 대시보드의 매뉴얼 보완 후보에 표시한다.
5. **공식 자료 링크 필드**: 규칙마다 선택적인 `externalReferenceUrl`을 두되, 링크 내용 자체를 제품의 판정 근거로 자동 사용하지 않는다.

### P0 이후 후보

- 소비기한 고객 불만 대응 시뮬레이션
- 택배·픽업 예외 처리 시뮬레이션
- 설비별 위생·마감 체크리스트
- 인수인계 상태와 확인 필요 항목
- 다국어·쉬운 문장 모드

### 제외하거나 사람의 확인이 필요한 것

- 실제 POS 조작 화면 및 실제 금전 처리 절차
- 금고, 시재, 담배 수불, 신분증 확인의 상세 내부 절차
- 특정 결제수단의 현재 정책을 확정적으로 안내하는 답변
- 법정 필수 교육을 자체 콘텐츠로 대체하는 기능
- 공개 영상 내용을 대량 전사·복제해 제품 데이터로 저장하는 행위

## 권장 데이터 구조

```ts
type TrainingReference = {
  id: string
  category: string
  subcategory?: string
  title: string
  sourceUrl: string
  sourceType: 'official-page' | 'video' | 'playlist' | 'external-channel'
  usage: 'reference-only' | 'scenario-inspiration' | 'official-handoff'
  reviewedAt: string
  requiresManagerConfirmation: boolean
}
```

이 구조는 공개 링크를 `참고 메타데이터`로만 보존하고, 실제 시뮬레이션의 사실·가격·행사·판정 규칙은 기존 합성 Seed와 분리한다.
