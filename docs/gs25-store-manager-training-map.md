# GS25 스토어매니저 교육맵 공개 자료 정리

> 출처: [GS25 스토어매니저 교육맵](https://hpimg.gsretail.com/images/gs25/winwin/web/store_manager_map.html)  
> 확인일: 2026-09-21  
> 활용 목적: 첫날.zip의 합성 시나리오·매뉴얼·체크리스트 후보를 설계하기 위한 공개 한국어 교육의 **본문 요약·분류·링크·수집 상태** 정리

## 먼저 지켜야 할 범위

- 이 문서는 공개 교육맵을 실제 브라우저로 열고 수집한 한국어 자료의 요약이다. 영상 원문 전체를 전사한 문서나 최신 점포 운영 매뉴얼은 아니다. 원문 대량 복제 대신 출처 링크와 핵심 내용을 보존한다.
- 실제 GS25 POS, 상품, 재고, 매출, 사내 시스템, 개인정보는 첫날.zip에 사용하지 않는다.
- 아래 항목을 제품에 적용할 때는 실제 브랜드·화면·수치 대신 가상 매장과 합성 상품·절차로 다시 설계한다.
- 법률·안전·결제·연령 확인 관련 내용은 오래되었거나 변경될 수 있으므로 서비스가 확정 답변하지 않고 최신 공식 지침 또는 경영주 확인으로 연결해야 한다.
- 원본 링크와 제공 상태는 변경될 수 있다. 구현 데이터로 고정하기 전에 링크 유효성과 공개 범위를 다시 확인한다.

## 수집 결과와 읽는 방법

> **상태: 한국어 자료 부분 수집, 전체 본문 수집은 미완료.** 모든 한국어 원본 링크와 추가 영상의 연결 페이지는 확인했지만, 아래 미확보 항목까지 수집했다고 주장하지 않는다.

| 대상 | 확인 결과 |
|---|---|
| 한국어 교육 영역 | 10개 팝업을 각각 실제로 열어 확인 |
| 원본 한국어 세부 링크 | 77개: 개별 영상 72개, 재생목록 2개, 외부 페이지 3개 |
| 재생목록 확장 | 청소 4편 + 배달·픽업의 신규 2편 = 추가 영상 6편 |
| 한국어 개별 영상 합계 | 중복 제거 78편 |
| 영상 본문 | 58편 스크립트를 확보·읽고 요약, 20편 미확보 |
| 하루완성 교육 | 45:53 영상의 화면상 목차 7개 확인, 전체 영상 본문 미확보 |
| 외부 페이지 | 우리동네GS 최신 공개 기능 설명, 챗봇조이 공개 소개·FAQ 확인. 구형 상세 링크 2개는 리디렉션 |
| 다국어 | 사용자 요청으로 수집·요약 범위에서 제외 |

수집일은 2026-09-21이다. 영상 길이는 재생기 표시 기준이며 재생목록 카드의 반올림 표시와 1초 정도 다를 수 있다. 영상 날짜나 제목에 들어 있는 연도는 최신 정책을 보장하지 않는다.

스크립트는 대부분 자동 생성 자막이다. 명백한 오인식은 문맥에 맞춰 요약했으나 불명확한 수치·화면 전용 정보는 확정하지 않았다. **본문 요약 확보**는 스크립트를 읽었다는 뜻으로, 영상의 모든 화면·음성·동작을 전수 검증했다는 뜻은 아니다. 본문과 기존의 `적용 메모`는 각각 출처 요약과 프로젝트 설계 의견으로 구분한다.

YouTube는 탐색 직후 추출하면 본문이 없다는 응답을 내다가 로딩 뒤에는 성공하기도 했다. 이를 확인해 로딩과 추출을 분리했다. 후반에는 브라우저 연결 정책 로딩 오류가 세 번 반복되어 미확보 자료의 추가 조작을 중단했다. 아래 상태 표시는 이 한계를 반영한다.

## 첫날.zip에 바로 반영할 우선순위

### P0 문서·Seed에 반영 가능한 것

1. **교육 분류 체계**: `고객 응대`, `상품·소비기한`, `안전·시설`, `POS`, `결제`, `서비스 판매`, `디지털 도구`를 매뉴얼 카테고리 후보로 사용한다.
2. **행동 중심 시뮬레이션**: 질문을 받으면 먼저 가상 POS 또는 매뉴얼을 조회하고, 근거가 없으면 경영주 확인을 요청하도록 한다.
3. **체크리스트 템플릿**: 상품 검수, 소비기한 확인, 진열/가격표 확인, 시설·위생 확인을 합성 항목으로 제공한다.
4. **미해결 질문 분류**: VOC, 소비기한, POS, 결제, 택배·픽업, 설비, 안전 등으로 태그해 경영주 대시보드의 매뉴얼 보완 후보에 표시한다.
5. **공식 자료 링크 필드**: 규칙마다 선택적인 `externalReferenceUrl`을 두되, 링크 내용 자체를 제품의 판정 근거로 자동 사용하지 않는다.

### P0 이후 후보

- 소비기한 고객 불만 대응 시뮬레이션
- 택배·픽업 예외 처리 시뮬레이션
- 설비별 위생·마감 체크리스트
- 인수인계 상태와 확인 필요 항목

### 제외하거나 사람의 확인이 필요한 것

- 실제 POS 조작 화면 및 실제 금전 처리 절차
- 금고, 시재, 담배 수불, 신분증 확인의 상세 내부 절차
- 특정 결제수단의 현재 정책을 확정적으로 안내하는 답변
- 법정 필수 교육을 자체 콘텐츠로 대체하는 기능
- 공개 영상 내용을 대량 전사·복제해 제품 데이터로 저장하는 행위

## 권장 데이터 구조

```ts
type TrainingReference = {
  id: string
  category: string
  subcategory?: string
  title: string
  sourceUrl: string
  sourceType: 'official-page' | 'video' | 'playlist' | 'external-channel'
  usage: 'reference-only' | 'scenario-inspiration' | 'official-handoff'
  reviewedAt: string
  requiresManagerConfirmation: boolean
}
```

이 구조는 공개 링크를 `참고 메타데이터`로만 보존하고, 실제 시뮬레이션의 사실·가격·행사·판정 규칙은 기존 합성 Seed와 분리한다.
